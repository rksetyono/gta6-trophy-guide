An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words with named sources, a three-stage roadmap to the platinum, missable flags, and a checklist that saves in the browser, exports to a file and imports back — with filters and a spoiler mode that hides story trophies until they are earned. No network needed: open `app/index.html` from any static server and it works with the network off.

## Run it

```sh
cd app && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. To hand the entry in, run `MAKEFUN_OUTPUT_DIR=out node main.ts`.
